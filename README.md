<summary><h3>🔎 &nbsp;RAG &amp; GraphRAG &nbsp;<sub><i>— semantics meets structure</i></sub></h3></summary>

<br/>

Hybrid retrieval that combines **vector similarity** with **explicit relationships**, fused and reranked before it ever reaches the model.

| Stage | What I use |
|:--|:--|
| 🔹 Vector | `pgvector` · embeddings · semantic search |
| 🔸 Graph | `Apache AGE` · entity &amp; relationship extraction |
| 🔀 Fusion | hybrid retrieval · Reciprocal Rank Fusion |
| 🎯 Refine | rerankers · retrieval optimization |
| 💾 Memory | conversational &amp; long-term memory |

</details>
